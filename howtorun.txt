HOW TO CREATE AND USE THE VENV (CLEAN SETUP)
Step 1: Create venv
python -m venv venv

Step 2: Activate venv
venv\Scripts\activate


You should see:

(venv)

Step 3: Install requirements
pip install -r requirements.txt

Step 4: Run the app
streamlit run app.py

5. IMPORTANT WINDOWS NOTES (VERY IMPORTANT)
✔ Python version

Use:

Python 3.10 or 3.11

Avoid: Python 3.12 (can cause issues with llama-cpp)

Check:

python --version


llama-cpp-python installation issues

If installation fails:

pip install llama-cpp-python --upgrade --force-reinstall
